Träningsloggen

Ett litet verktyg (byggt med HTML, CSS och JavaScript) för att logga vikter och reps mellan träningspass. Tanken är enkel: progressiv överbelastning går inte att sköta på minnet — utan en logg vet man inte om man faktiskt blir starkare vecka för vecka.

Vad loggen sparar

Övning, vikt, reps och antal set per pass — så att jag kan gå tillbaka och se exakt vad jag lyfte förra veckan innan jag börjar samma övning igen.

Varför det spelar roll

Om jag inte vet vad jag lyfte förra gången, vet jag inte om jag ska öka vikten, lägga till en rep, eller hålla mig kvar. Loggen gör progressionen synlig istället för en gissning.
