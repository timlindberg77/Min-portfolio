12-veckors träningsprogram

Mitt program bygger på science based lifting — träning baserad på forskning kring hypertrofi (muskeltillväxt) snarare än magkänsla eller trender. Grunden är enkel: tillräcklig volym, tillräckligt nära failure, och konsekvent progression över tid.

Jag kör en Push / Pull / Legs-split kombinerad med Upper / Lower-pass, vilket ger mig fem träningspass per vecka och gör att varje muskelgrupp tränas två gånger i veckan — vilket forskning visar ger bättre resultat än att bara träffa en muskelgrupp en gång per vecka.

Push (bröst, axlar, triceps)
Pull (rygg, biceps)
Legs (ben, säte)
Upper (överkropp, helhet)
Lower (underkropp, helhet)

Set & failure

Jag kör 2 arbetsset per övning, tagna nära eller till failure (muskulär utmattning). Att träna nära failure är det som verkar driva flest muskelfibrer att växa — poängen är inte antalet set i sig, utan hur nära gränsen varje set tar dig.

Veckovolym

Målet är 10–20 arbetsset per muskelgrupp och vecka, vilket enligt forskningen ligger i det sötaste läget för tillväxt hos de flesta — tillräckligt för stimulans utan att gå in i överträning eller sämre återhämtning.

Genom att kombinera PPL och Upper/Lower kan jag träffa varje muskelgrupp två gånger i veckan med korta, effektiva pass — istället för långa pass en gång i veckan där de sista seten sällan ger lika mycket tillbaka.
